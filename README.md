# Subhash Jugran Portfolio

Static portfolio website ready for Amazon S3 static hosting.

## Files
- index.html
- styles.css
- script.js
- subhash-jugran-profile.png
- Subhash_Jugran_Resume.pdf

## Local preview
Open `index.html` directly in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`

## S3 hosting
Upload all files to your S3 bucket and set `index.html` as the index document.

## Quick edits
- Hero content: `index.html`
- Skills / certifications / projects: `index.html`
- Colors / spacing / layout: `styles.css`
- Tabs / mobile menu: `script.js`
